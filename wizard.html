Enter your existing WiFi network credentials. The ESP32-S3 will join this network — no hotspot is created.
The name of the WiFi network your ESP32-S3 will connect to.

Router (Ad Blocker Service)
Enter your router's IP address. The ESP32-S3 will test each ad domain against the router ad blocker service and only block the ones the router can't handle.
Why this matters: The ESP32-S3 tests 129 ad/tracker domains from adblock.turtlecute.org against your router. If the router can already block a domain, the ESP32-S3 skips it — avoiding duplicate blocking and saving memory.
The IP address of your router running ad blocker service. Usually 192.168.1.1 or 192.168.50.1.
Dashboard Password
This is a local password that protects your ESP32-S3 management dashboard. It is NOT a third-party API key (no Brave, Google, or external service needed). It only exists between your browser and the ESP32-S3 on your local network.

Pick your own dashboard password
You'll need this key to log into the dashboard.
What is this? This is just a local password for your dashboard — like a Wi-Fi password but for the admin panel. No external registration needed. Nothing is sent to any external service.
After flashing: If you chose auto-generate, the password appears on the first-run wizard page at http://esp32-pihole.local. If you chose custom, use the one you set here.
Review Your Configuration
Check everything looks right, then save your config file. Click "Save to firmware/data/wifi_config.json" to write it directly, or use Download to save it manually.
Flash Your ESP32-S3
Connect your ESP32-S3 via USB, then click the button below to flash the firmware directly from your browser — no terminal needed.
Before you flash: Make sure you saved wifi_config.json to firmware/data/ in Step 4. The flash button below sends the firmware + your config file to the ESP32-S3 over USB.

Connect your ESP32-S3 via USB cable, then click "Connect" above.

Web Serial not supported? If your browser doesn't support web-based flashing:
  1. Install PlatformIO
  2. Run: pio run --target upload (flash firmware)
  3. Run: pio run --target uploadfs (flash filesystem with your config)
